# MOATV Brand Keyword Optimization Report

## Objective

Focused brand keyword optimization for the exact keyword `moatv` across the current Next.js website, while preserving URLs, blog slugs, design, pricing logic, sitemap, robots, canonicals, and structured data.

## Keyword Occurrence Count

- Before: 2 exact lowercase `moatv` occurrences in `src`.
- After: 101 exact lowercase `moatv` occurrences in `src`.

The increase was made through natural headings, metadata, body copy, FAQ copy, internal anchor text, and article copy. No hidden text or keyword-stuffing patterns were added.

## Metadata Modified

- Home title/description now target `moatv IPTV`.
- Pricing title/description now target `moatv IPTV Pricing` and comparison intent.
- Devices title/description now connect `moatv IPTV` with device support.
- FAQ title/description now target `moatv IPTV FAQ`.

- Reseller title/description now target `Become a moatv Reseller`.
- Legal metadata now includes natural `moatv` policy phrasing.
- Global site description and `seoName` now use `moatv IPTV`.

## Important Body Copy Changes

- Homepage hero and intro copy now clearly associate `moatv` with IPTV plans, device compatibility, and setup guidance.
- Device copy now explains `moatv` setup across common living-room and mobile devices.
- Pricing copy now asks users to choose a `moatv` subscription term.
- FAQ questions now include natural brand-specific search intent such as `What is moatv IPTV?` and `Which devices work with moatv?`.
- Reseller copy now removes stale contact-page language and frames the page around `moatv` reseller preparation.
- Blog article copy now references `moatv` setup, login methods, and support where relevant.

## Internal Anchor Changes

- `Device guidance` became `moatv devices` where context supported it.
- `View pricing` / `Compare pricing` became `moatv pricing`.
- `Browse FAQ` became `moatv FAQ`.
- Blog index featured link became `Read moatv guide`.
- Reseller hero CTA became `moatv Reseller Details`.

Navbar labels remain intentionally unbranded: Home, Pricing, Devices, FAQ, Blog, Reseller.

## Headings Deliberately Not Branded

- Device H4 headings remain concise: Fire TV / Firestick, Android TV, Google TV, Samsung Smart TV, LG Smart TV, Apple TV, Phones and tablets, Computers. The parent H3 already says `Use moatv on the devices you already own.`
- Blog utility headings `Contents` and `Next steps` remain unbranded because adding `moatv` would be mechanical.
- Several reseller card headings remain unbranded because nearby H1/H2 headings already establish `moatv` context.
- Legal page H1 headings remain standard policy names for clarity; each page's metadata and H2 now carry the brand.
- Navbar and footer navigation labels remain unbranded for clean UX.
